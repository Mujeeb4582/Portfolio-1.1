**Focus indicators (A11Y-01, A11Y-02):**

Add a global `:focus-visible` rule inside `@layer base` that applies a visible focus ring to ALL interactive elements. This must work across all three themes without overriding the existing `* { @apply border-border }` rule.

Add after the existing body rule inside `@layer base`:

```css
:focus-visible {
  outline: 2px solid var(--color-brand1);
  outline-offset: 3px;
  border-radius: var(--radius-sm);
}

/* Remove default outline only when :focus-visible is supported */
:focus:not(:focus-visible) {
  outline: none;
}
```

Using `--color-brand1` (#12F7D6) ensures the focus ring is visible on all three themes (dark bg, light bg, midnight_steel bg) because it is a high-contrast accent color against all background values. Brand1 (#12F7D6) on dark bg (#1A1E23): contrast ratio ~9.4:1. Brand1 on light bg (#FFFFFF): contrast ratio ~1.7:1 — insufficient alone on light mode, so also add a 3px offset creating a gap that prevents the ring from merging with element backgrounds.

For light mode specifically, ensure focus rings are distinguishable by adding a box-shadow fallback:
```css
:focus-visible {
  outline: 2px solid var(--color-brand1);
  outline-offset: 3px;
  border-radius: var(--radius-sm);
  box-shadow: 0 0 0 4px oklch(from var(--color-brand1) l c h / 0.2);
}
```

**Contrast audit (A11Y-03):**

Audit the existing muted-foreground tokens:
- Light mode: `--color-muted-foreground: hsl(25 5.3% 44.7%)` = approx #716C68 on white #FFFFFF. Calculate: relative luminance of #716C68 ≈ 0.182, on #FFFFFF (1.0) → ratio = (1.0 + 0.05) / (0.182 + 0.05) = 4.52:1. This barely passes 4.5:1. Leave as-is.
- Dark mode: `--color-muted-foreground: hsl(24 5.4% 63.9%)` = approx #A49E99 on #0D0B0A background. Luminance of #A49E99 ≈ 0.362, on #0D0B0A (0.006) → ratio = (0.362 + 0.05) / (0.006 + 0.05) = 7.36:1. Passes.
- midnight_steel card-foreground: `hsl(213 11% 76%)` = approx #BABEC9 on card `hsl(213 15% 12%)` = #1A1E26. Luminance #BABEC9 ≈ 0.498, on #1A1E26 (0.017) → ratio = (0.498 + 0.05) / (0.017 + 0.05) = 8.19:1. Passes.

No contrast token changes needed. Document this audit outcome in a CSS comment inside globals.css above the focus rule:

```css
/* Contrast audit (WCAG 2.2 AA — 4.5:1 minimum):
   Light: muted-foreground #716C68 on #FFFFFF → 4.52:1 ✓
   Dark: muted-foreground #A49E99 on #0D0B0A → 7.36:1 ✓
   midnight_steel: card-foreground #BABEC9 on #1A1E26 → 8.19:1 ✓ */
```
