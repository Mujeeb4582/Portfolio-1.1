  <action>
Create `vercel.json` in the project root with the following configuration:

```json
{
  "framework": "nextjs",
  "buildCommand": "bun run build",
  "installCommand": "bun install",
  "devCommand": "bun run dev"
}
```

`RESEND_API_KEY` is configured via Vercel Project Settings → Environment Variables, not in `vercel.json`. The legacy `@secret-name` syntax and the `env` block in `vercel.json` are discouraged by Vercel — Project env vars are the single source of truth and are automatically injected into build and runtime.

After creating vercel.json, run a final production build to confirm everything compiles:
```bash
bun run build
```

If the build fails, diagnose and fix the issue before proceeding to the checkpoint. Common issues:
- TypeScript errors (run `bunx tsc --noEmit` to check)
- Missing public assets (project screenshots, profile image)
- OG image route errors (check app/opengraph-image.tsx)
  </action>

    <automated>cd  && bun run build 2>&1 | tail -30</automated>
  </verify>

    - grep -n "bun run build" vercel.json returns a match
    - bun run build exits with code 0 (no build errors)
  </acceptance_criteria>
