## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps, inline icon padding |
| sm | 8px | Compact element spacing (button icon gap, badge padding) |
| md | 16px | Default element spacing (card internal padding, form fields) |
| lg | 24px | Section inner padding, between-element gaps |
| xl | 32px | Between major blocks within a section |
| 2xl | 48px | Section-level vertical padding (top/bottom of each section) |
| 3xl | 64px | Reserved for page-level top margin / navbar clearance |

Exceptions:
- Hero section min-height: `min-h-screen` (100vh) — spans full viewport
- Touch targets for social icon links: minimum 44px (using `p-2` + `size-5` icon = 40px; use `p-2.5` where needed to reach 44px)
- Timeline dot size: 14px (3.5 Tailwind units) — design exception for visual proportion
- Hero photo: 380×460px at `width={380} height={460}` — fixed dimension from RESEARCH.md pattern

Source: Standard 8-point scale (default); exceptions from CONTEXT.md and RESEARCH.md

## Typography

### Token Definitions

All tokens must be added to `app/globals.css` under `@theme {}` before section components are built. They are currently referenced in components but NOT defined in globals.css — this is a Phase 2 implementation gap.

| Token | Font | Size | Weight | Line Height | Usage |
|-------|------|------|--------|-------------|-------|
| `text-h2-u` | Inter | 36px | 700 (bold) | 1.2 | Section headings, hero name, hero title |
| `text-h2-m` | JetBrains Mono | 28px | 700 (bold) | 1.2 | Hero "Let's Talk" accent |
| `text-number-m` | JetBrains Mono | 28px | 700 (bold) | 1.2 | Stat numbers in hero and about |
| `text-para-m` | JetBrains Mono | 16px | 400 (regular) | 1.5 | Body paragraphs, bios, skill names, responsibilities |
| `text-code-m` | JetBrains Mono | 14px | 400 (regular) | 1.5 | Code tag decoration, meta text, date ranges |
| `text-button-u` | Inter | 14px | 600 (semibold) | 1 | Button labels |
| `text-label-u-m` | Inter | 12px | 400 (regular) | 1.5 | Stat card sub-labels, category labels |
| `text-logo-m` | JetBrains Mono | 24px | 700 (bold) | 1.2 | Logo/name display (carry-forward, used in hero) |

### Summary Table (4 sizes, 2 weights)

| Role | Size | Weight | Line Height | Font |
|------|------|--------|-------------|------|
| Display / Heading | 36px | 700 bold | 1.2 | Inter |
| Sub-heading / Accent | 28px | 700 bold | 1.2 | JetBrains Mono |
| Body / Paragraph | 16px | 400 regular | 1.5 | JetBrains Mono |
| Label / Meta | 14px | 400 regular | 1.5 | JetBrains Mono |

Weights used: 400 (regular) and 700 (bold). No intermediate weights.

Note: `text-button-u` at 14px / 600 semibold is the only Inter body size — used exclusively on button labels. The semantic distinction is font family (Inter vs JetBrains Mono), not additional weight values.

Source: `app/ui/homepage/heroSection.tsx` token usage, `.planning/codebase/STACK.md` font token documentation, defaults applied for pixel values

## Color

### Theme Variables

The portfolio has three themes: `light`, `dark`, `midnight_steel` (default). All colors are CSS custom properties in `app/globals.css`.

| Role | Light value | Dark value | Midnight Steel value | Usage |
|------|-------------|------------|---------------------|-------|
| Background (dominant 60%) | `hsl(0 0% 100%)` white | `hsl(20 14.3% 4.1%)` near-black | `hsl(210 13% 19%)` `#292F36` | Page background, section fills |
| Card surface (secondary 30%) | `hsl(0 0% 100%)` | `hsl(20 14.3% 4.1%)` | `hsl(213 15% 12%)` `#1A1E23` | Cards (skill cards, experience cards, stat cards), navbar |
| Brand accent (10%) | `#12F7D6` (`--color-brand1`) | `#12F7D6` | `#12F7D6` | See reserved-for list below |
| Brand accent 2 | `#98FAEC` (`--color-brand2`) | `#98FAEC` | `#98FAEC` | Education timeline dots only |
| Foreground | `hsl(20 14.3% 4.1%)` | `hsl(60 9.1% 97.8%)` | `hsl(210 10% 95%)` | Body text |
| Muted foreground | `hsl(25 5.3% 44.7%)` | `hsl(24 5.4% 63.9%)` | `hsl(60 9.1% 97.8%)` | Secondary text (dates, meta, labels) |
| Destructive | `hsl(0 84.2% 60.2%)` | `hsl(0 62.8% 30.6%)` | `hsl(0 62.8% 30.6%)` | Not used in Phase 2 (no destructive actions) |

### Accent Reserved-For List

`#12F7D6` (`brand1`) is used ONLY on these specific elements:

1. Hero photo border: `border-brand1` + glow `shadow-[0_0_24px_rgba(18,247,214,0.25)]`
2. Hero greeting label: `"Hi, my name is"` monospace label text
3. Social icon links: hover state color on GitHub, LinkedIn, Email, WhatsApp icons
4. Section heading underline decoration: the `<UnderLine />` component's dot and line (`bg-brand1`, `border-brand1`)
5. Timeline vertical line: `bg-brand1/30` (30% opacity) for the connecting line
6. Timeline work-experience dots: `border-brand1 bg-background` (circle dot)
7. Stat numbers in hero and about: `text-brand1`
8. Primary CTA button background (via `bg-primary` → overridden to accent in dark/midnight themes): use `bg-brand1 text-black` as primary button style
9. Skill icon color: `text-brand1` on tech brand icons in skill grid

`#98FAEC` (`brand2`) is used ONLY on:
1. Education timeline dots: `border-brand2` (square dot, visually distinct from work)
2. Code tag decoration text (e.g. `<h1>`) — carry-forward pattern from old heroSection if retained

Source: `app/globals.css`, `01-CONTEXT.md` (locked decisions), `02-CONTEXT.md`, `02-RESEARCH.md`

## Implementation Notes for Executor

1. **Typography token gap:** The tokens `text-h2-u`, `text-para-m`, `text-number-m`, `text-code-m`, `text-h2-m`, `text-logo-m`, `text-button-u`, `text-label-u-m` are USED in existing components but NOT defined in `app/globals.css`. Add these to the `@theme {}` block before building sections.

   ```css
   @theme {
     /* Typography scale additions */
     --font-size-h2-u: 2.25rem;      /* 36px */
     --font-size-h2-m: 1.75rem;      /* 28px */
     --font-size-number-m: 1.75rem;  /* 28px */
     --font-size-logo-m: 1.5rem;     /* 24px */
     --font-size-para-m: 1rem;       /* 16px */
     --font-size-code-m: 0.875rem;   /* 14px */
     --font-size-button-u: 0.875rem; /* 14px */
     --font-size-label-u-m: 0.75rem; /* 12px */
   }
   ```

2. **Profile photo blocker:** `/profile.jpg` does not exist in `public/`. Plan must include a task to add it before hero section is considered complete.

3. **Resume PDF blocker:** `/mujeeb-resume.pdf` does not exist in `public/`. Use a placeholder PDF or document the blocker clearly in the plan.

4. **react-icons install:** Run `bun add react-icons` before Skills section work begins.

5. **No `'use client'` on section components:** Hero, About, Skills, Experience are all Server Components. None require client-side interaction in Phase 2.

6. **Heading hierarchy:** The hero `<h1>` is `PERSONAL_INFO.name`. All section headings (`<h2>`) follow. Sub-headings in experience cards use `<h3>`. Do not skip levels.

7. **Primary CTA button color:** The shadcn default `bg-primary` in midnight_steel resolves to near-white. For the hero primary button to use brand cyan (`#12F7D6`) as background, apply `className="bg-brand1 text-black hover:bg-brand1/90"` to override the default. This is the intentional design for the accent-colored primary action.
